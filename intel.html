Data sources

CISA Known Exploited Vulnerabilities — authoritative exploited-vulnerability catalog. The app reads the JSON mirror maintained by CISA on GitHub, with a fallback to the official CISA feed.

FIRST EPSS — probability estimate for exploitation activity over the next 30 days, queried when you inspect a CVE.

NIST NVD — direct links to CVE detail records for further research.

Assessment boundary

The public website accepts typed identifiers for research, not uploaded files or imported reports. Existing scan evidence and inventories stay within your internal assessment tools. No remote scanning or execution occurs on GitHub Pages.

Global host exposure search, a backend service, and exploit-specific validation beyond safe configuration probes are future modules, not implemented capabilities.
