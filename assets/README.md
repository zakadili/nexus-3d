# Bundled asset attribution

- Mapping bundle: D3 7.9.0 (ISC), TopoJSON Client 3.1.0 (ISC). Exact dependencies and licenses are retained in package-lock.json and THIRD-PARTY-LICENSES.txt.
- countries-110m.json: World Atlas 2.0.2, ISC; Natural Earth cartographic data is public domain.
- country-codes.json: ISO-3166 country-code mapping from lukes/ISO-3166-Countries-with-Regional-Codes (CC BY-SA 4.0). Downloaded 2026-11-11; names are displayed using the browser's English region names.
- Barlow Condensed: Jeremy Tribby, SIL Open Font License 1.1.
- DM Mono: Colophon Foundry / Google, SIL Open Font License 1.1.
- social-card.png and favicon.svg: NEXUS project artwork.

Assets are served locally; opening the map makes no requests to font or JavaScript CDNs.
