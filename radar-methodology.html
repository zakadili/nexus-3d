What the map represents

The map plots geolocated source IP addresses appearing in the SANS Internet Storm Center / DShield sensor reports. A marker denotes the country associated with one or more source network addresses, not the physical location or nationality of a threat actor. A source may be a benign scanner, compromised server, cloud instance, proxy, or malicious host. The source-IP selection is a small high-ranking sample, not a global census.

What the counters mean

  • Sampled source IPs: number of distinct source IP records obtained from the current top-IP feed.
  • Reports in sample: sum of reported packet records across those sampled IPs; this is neither total global attacks nor distinct exploitation events.
  • Source countries: number of country codes resolved for sampled source IPs. Unresolved IPs are excluded from this counter.
  • Top targeted port: a separate DShield report summarizing destination ports in its sensor sample. It is not paired to any source IP in the top-IP list.
  • Refresh timestamp: collection time, not the timestamp of an individual attack. DShield source/port windows can differ.

Sources and licensing

SANS Internet Storm Center / DShield API documentation — published source-IP and port observations. DShield asks for attribution, courteous API use, and no resale. Its documentation describes the public API data license as CC BY-NC-SA 4.0. Data is attributed and not included as a permanent dataset in the software repository.

ipwho.is — approximate IP geolocation via HTTPS. A source's country is a location estimate for network infrastructure, not an attribution judgment. Free usage is rate-limited.

Refresh and fallback

The browser implementation caches results for one hour per visitor to avoid unnecessary upstream requests. The optional local FastAPI collector stores one server-side snapshot per hour and can serve stale, explicitly labeled cache if upstream services fail. A failed fetch without prior data displays an error and no invented counters.

Important distinction: geographic CVEs

CVEs describe vulnerabilities in products, not countries. A global country vulnerability-exposure heatmap requires legally sourced internet exposure measurements plus product/version evidence, and meaningful uncertainty labels. This version maps observed network-source infrastructure, not affected-device prevalence or verified CVE exploitation by country.

Authorized assessment

NEXUS retains a separate scope-controlled Python active scanner and a synthetic attack-path lab. Neither the radar nor the data-collection API scans arbitrary targets. Source IPs displayed in this feed must never be treated as automatic targets or a blocklist.
